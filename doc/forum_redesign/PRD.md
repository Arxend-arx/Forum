---

## 1. 项目背景

现有 `Forum_test/forum_project` 为 Flask + Jinja2 + SQLite3 的**前后端不分离单体架构**：后端直接渲染 HTML 模板，前端无独立工程、无 i18n、无主题系统、样式内联。现需将其重构为**前后端分离架构**，并对前端交互页面进行**视觉、布局、风格层面的重新设计**。

## 2. 项目目标

1. **架构分离**：后端提供纯 REST API（JSON），前端为独立 React 工程，前后端分离部署（含 CORS）。
2. **视觉升级**：重新设计全部前端页面（信息架构、布局、视觉风格），输出三款可对比的 HTML 原型供确认。
3. **国际化**：支持中文 / 英文双语切换（i18n），语言偏好持久化。
4. **主题系统**：支持浅色 / 深色双主题，主题偏好持久化并跟随系统（可选）。
5. **功能无损**：现有全部功能迁移到新架构，不丢失任何能力。

## 3. 用户角色

| 角色 | 说明 |
|---|---|
| 游客 | 浏览帖子、搜索、查看用户资料；不可发帖/评论/聊天 |
| 登录用户 | 发帖、评论、关注、好友、私信、学术匹配、LLM 配置等全部功能 |
| 管理员（预留） | 系统级 LLM 配置（本期不做管理端，LLM 由用户自行在页面配置） |

## 4. 功能需求

### 4.1 用户认证
- 注册：用户名唯一、非空校验、重复用户名提示。
- 登录：校验账号密码，成功后服务端签发会话；前端保存会话状态。
- 退出登录：清除会话并跳转。
- 会话保持：刷新页面保持登录态；未登录访问受保护页面时提示并引导登录。

### 4.2 帖子
- 帖子列表（首页）：时间倒序，展示标题、摘要、作者、评论数。
- 发帖：标题 + 正文（Markdown 语法），正文支持图片/视频嵌入。
- 帖子详情：完整正文（Markdown 渲染）、作者信息、评论列表。
- 删帖：仅作者可删，级联删除评论，需确认。

### 4.3 评论
- 发表评论：非空校验；支持 `@用户名` 提及（转为站内链接 + 系统通知被提及者）。
- 删除评论：仅评论作者可删。

### 4.4 搜索
- 关键词匹配帖子标题/正文 + 用户名；结果分"帖子 / 用户"两类展示。

### 4.5 个人资料与关注
- 资料页：头像、用户名、签名、学习意向、关注数/粉丝数、关注列表、粉丝列表、最近帖子。
- 编辑资料：头像、签名、学习意向。
- 关注/取消关注：不能关注自己；状态即时反馈。

### 4.6 好友系统
- 发送好友请求（自动通知对方）。
- 请求管理页：我收到的 / 我发出的（pending）。
- 接受：建立双向好友关系并通知对方；拒绝：删除请求。
- 解除好友关系。

### 4.7 私信聊天
- 聊天主页：好友列表 + 最近对话（含未读数）。
- 聊天详情：往来消息时间线、富文本发送框、仅好友可聊。
- 打开会话标记已读。

### 4.8 消息通知
- 信件箱（通知中心）：系统通知列表（@提及、好友请求、接受通知等），打开后自动已读。
- 导航未读徽标实时显示。

### 4.9 文件上传
- 图片（jpg/png/gif/webp 等 ≤5MB）与视频（mp4/webm 等 ≤100MB）上传，返回可引用 URL。

### 4.10 学术匹配
- 入口页：学习意向预填、LLM 可用状态、文献源（OpenAlex）可用状态展示。
- 检索：关键词（可叠加学习意向）→ OpenAlex 免费 API 检索科技文献（论文，无需 Key / 企业认证）。
- LLM 分析：可选，用户自配模型对结果做匹配度摘要（Markdown 展示）。
- 结果页：文献列表 + 摘要 + 错误信息。
- 历史记录：检索历史列表。

### 4.11 LLM 设置
- 配置 base_url / api_key / model（OpenAI 兼容）。
- 连接测试：调用模型返回简短回复验证。

## 5. 新增强化需求（本次重构新增）

### 5.1 国际化（i18n）
- 支持 **zh-CN / en-US** 两种语言。
- 所有界面文案可切换；切换即时生效并持久化（localStorage）。
- 用户生成内容（帖子、评论、资料）保持原样，不做翻译。

### 5.2 主题系统
- 支持 **浅色（light）/ 深色（dark）** 双主题。
- 切换即时生效并持久化（localStorage）；默认跟随系统偏好。
- 全部页面/组件遵守主题设计令牌（CSS Variables），无硬编码颜色。

### 5.3 视觉与交互重设计
- 重新设计信息架构与页面布局（导航、内容区、操作区）。
- 统一设计令牌：颜色、间距、圆角、阴影、字体、动效。
- 交互细节：加载态、空态、错误态、Toast 提示、确认弹窗、响应式（移动端适配）。

## 6. 非功能需求

| 类别 | 要求 |
|---|---|
| 性能 | 首屏加载轻量；列表分页/惰性加载；静态资源构建压缩 |
| 安全 | 密码不明文存储（沿用现状，本期可顺带升级为哈希）；SQL 参数化；上传类型/大小校验；XSS 防护（前端渲染转义） |
| 兼容 | 现代浏览器（Chrome/Edge/Firefox/Safari 最近两个大版本） |
| 可维护 | 前端组件化、目录分层清晰；后端 API 文档化（OpenAPI 或等价说明） |
| 数据 | 数据库为 **PostgreSQL 16**（独立容器），`init_db()` 幂等建表 + 兼容迁移，不破坏现有数据（旧 SQLite 存量经 `scripts/migrate_sqlite_to_pg.py` 迁移） |

## 7. 技术约束

- 后端：Python Flask（新增 `flask-cors`），提供 `/api/*` REST 接口；复用 `academic_match.py` 业务模块。
- 前端：React 18 + Vite + React Router + react-i18next（i18n）+ CSS Variables（主题）。
- 部署：前后端分离部署；开发期 Vite dev server 代理 `/api`，生产期 Nginx 反代或同机双端口。
- 重构在 `Forum_test` 仓库进行，完成后同步至 `Forum` 仓库。
